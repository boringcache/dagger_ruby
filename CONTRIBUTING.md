# Contributing

Bug reports and focused pull requests are welcome.

1. Search existing issues before opening a new one.
2. Fork the repository and create a short, descriptive branch.
3. Run `bin/setup`, make the smallest useful change, and add tests.
4. Run `bin/ci`.
5. For Dagger API changes, also run the engine-backed suite from the README.
6. Open a pull request explaining the behavior change and verification.

Please do not include generated gems, dependency directories, credentials, or
personal data. By participating, you agree to follow the
[`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
